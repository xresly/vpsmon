# vpsmon

一个单二进制的 VPS 监控面板：一键脚本安装，浏览器打开 WebUI，
在界面里分别开启「服务端」和「客户端」角色，不用再手写配置文件。

- **客户端**：装在每台被监控的 VPS 上，每分钟采样，每 5 分钟向服务端汇报一次
  CPU、内存、磁盘和流量。流量的记账全部在客户端完成（重启不丢、断网不丢）。
- **服务端**：装在一台机器上，接收各客户端的汇报，在看板上汇总展示。
  服务端不做任何计算，只展示客户端算好的数字。
- 一台机器可以只开客户端、只开服务端，或者两个都开（服务端通常也会把自己接入）。
- 流量单位统一用 **G**（1 G = 1024³ 字节）。
- 纯 Go 标准库实现，零依赖，单个静态二进制（amd64 / arm64）。

## 一键安装

```bash
bash <(curl -Ls https://raw.githubusercontent.com/xresly/vpsmon/main/install.sh)
```

安装过程会依次询问 WebUI 端口、用户名、密码（直接回车则随机生成），
完成后打印面板地址和登录凭据。指定版本：

```bash
bash <(curl -Ls https://raw.githubusercontent.com/xresly/vpsmon/main/install.sh) v1.0.0
```

已安装过再跑一次同一脚本就是升级：只替换二进制，配置和账本都保留。

安装后：

- 服务由 systemd 管理：`systemctl status vpsmon`
- 命令行管理菜单（改端口、重置密码、换 token 等）：`vpsmon menu`
- 配置文件：`/etc/vpsmon/config.json`（由程序自己管理，密码只存哈希）
- 客户端账本：`/var/lib/vpsmon/state.json`

如果服务器开了防火墙，记得放行面板端口，例如 ufw：`ufw allow <端口>/tcp`。

## 首次使用

1. 浏览器打开安装完成时打印的面板地址，用安装时设置的用户名密码登录。
2. **在一台机器上开启服务端**：进入「服务端」页，勾选启用，记下上报 token
   （ingest token，也可以点随机生成）。
3. **在每台被监控的机器上开启客户端**：进入「客户端」页，勾选启用，填：
   - 服务端地址：服务端的面板地址，到端口为止，如 `https://1.2.3.4:2053`
   - 上报 token：第 2 步那个 token
   - 节点名：任意，如 `acck-hkstd`
   - 流量配额（G）、每月重置日（1–28）、到期日
   - 初始已用流量（G）：把接入这一刻服务商面板上显示的当月已用填进来，
     客户端会从这个数接着往下记
   - 计费口径：默认 `both`（上下行相加）；若服务商只按出站计费选 `out`，
     取大值选 `max`
4. 保存后客户端立即开始汇报，看板上 1 分钟内出现该节点。

## 看板

每个节点一行：在线状态（超过 10 分钟没汇报标红离线）、CPU（即时值与 5 分钟均值）、
内存、磁盘、当月已用/配额（带进度条，超 80% 变黄、95% 变红）、剩余流量、
过去 5 分钟用量、累计用量、下次重置日、到期日与剩余天数。页面每 60 秒自动刷新。

只读 API：`GET /api/nodes`，用设置页里的 API token（`Authorization: Bearer <token>`）
或登录会话访问，返回同样的 JSON 数据，方便接日报/告警脚本。

## 操作说明

- **改配额/套餐**：在该节点的「客户端」页改配额保存即可，历史账不受影响。
- **改重置日**：重置日决定记账周期，改完当月已用会重新起算；改之前先看一眼服务商
  面板当前的已用量，改完用下面的「重新播种」把这个数填回去。
- **重新播种**：「客户端」页底部，清空本机账本，把当月已用设为指定数值重新开始。
  账对不上、换套餐时用。
- **改面板端口/密码**：「设置」页直接改，端口修改保存后立即在新地址监听，
  页面会给出新地址。命令行兜底：`vpsmon menu`。
- **换上报 token**：「服务端」页随机生成后，所有客户端都要同步改 token。
- **节点离线**：先去那台机器看 `systemctl status vpsmon` 和「客户端」页的状态区
  （会显示最近一次汇报是否失败及原因）。服务端宕机不丢账：客户端的账记在本地，
  服务端恢复后下一次汇报就是完整数字。

## 设计要点

- **记账在客户端**：客户端直接读网卡计数器（默认路由对应的物理网卡），每分钟采样
  并把状态持久化到本地。重启后计数器清零的情况用 boot_id 变化识别，增量不会丢
  也不会重复；服务端重启、网络中断都不影响账的正确性。
- **服务端只展示**：服务端把每个节点的最新一份报告存在内存里，不落库、不汇总、
  不二次计算。服务端重启后，各节点 5 分钟内自动报回。
- **种子只生效一次**：初始已用只在账本不存在（首次运行或重新播种）时写入，
  之后改配置不会重复叠加。
- **周期滚动**：按重置日（本地时间）划分计费周期，跨过重置日自动清零种子、
  从当前累计值重新起算。
- **安全**：面板密码 PBKDF2-HMAC-SHA256 加盐哈希存储；登录失败 5 次锁定 10 分钟；
  上报与读取使用两套独立 token，均以常量时间比较；所有写操作带 CSRF token。
  面板支持填证书路径启用 HTTPS（证书续期后自动重读，无需重启）。

## 从源码构建

需要 Go 1.24+：

```bash
git clone https://github.com/xresly/vpsmon.git
cd vpsmon
go build -ldflags "-s -w" -o vpsmon .
./vpsmon init -config ./vpsmon.json -port 2053 -username admin -password '改成你的密码'
./vpsmon run -config ./vpsmon.json
```

## 卸载

```bash
systemctl disable --now vpsmon
rm -f /etc/systemd/system/vpsmon.service /usr/local/bin/vpsmon
rm -rf /etc/vpsmon /var/lib/vpsmon
systemctl daemon-reload
```
